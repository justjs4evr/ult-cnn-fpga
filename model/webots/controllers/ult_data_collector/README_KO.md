# Webots ULT-CNN 자료 수집 (첫 단계)

## 실행

Webots에서 `C:\AICAR\webot\worlds\ult_data_collection.wbt`를 열고 재생합니다. **Num Lock을 켠 뒤** 3D 화면을 클릭해 키보드 입력을 전달하세요. 기존 `3cam_aicar.wbt`는 변경하지 않았습니다.

| 키 | 동작 |
|---|---|
| ↑ / ↓ | 전진 / 후진 |
| ← / → | 조향 (전진/후진과 함께 누름) |
| Space | 정지 |
| 키패드 8 | 직진 (`straight`, 클래스 0) |
| 키패드 7 | 좌회전 (`left`, 클래스 1) |
| 키패드 4 | 급좌회전 (`sharp_left`, 클래스 3) |
| 키패드 9 | 우회전 (`right`, 클래스 2) |
| 키패드 6 | 급우회전 (`sharp_right`, 클래스 4) |
| 키패드 5 | 정지선 (`stop`, 클래스 5) |
| R | 기록 시작 / 재개 |
| S | 기록 일시정지 |
| Q | 수집 종료 |

먼저 클래스를 선택하고 R로 기록을 켭니다. 구간이 바뀌면 기록 중에도 해당 클래스 키를 바로 누르면 됩니다. 오래 멈춰 있을 때는 S로 기록을 일시정지하고, 다시 출발할 때 R로 재개하세요. R을 여러 번 눌러도 기록이 꺼지지 않습니다. 클래스는 **카메라에 보이는 트랙 상황**을 뜻하며, 그 순간 눌러 운전한 조향 키와 별개입니다. `stop`은 정지선이 보이는 프레임에만 부여하세요. 현재 트랙 그림에 횡단보도처럼 생긴 표시가 있으므로 정지선 여부는 사람이 확인해야 합니다. Num Lock을 끄면 일부 키패드 키가 방향키로 처리될 수 있습니다.

## 저장 결과

`dataset/images/`에 저장 시점마다 중앙·좌·우 카메라 JPEG가 각각 하나씩 저장됩니다. 바퀴 센서 기준으로 약 2cm 이동하거나 9도 회전했을 때 저장하며, 연속 저장 간격은 최소 0.2초입니다. 정지한 상태에서는 같은 장면을 반복 저장하지 않습니다. 클래스를 새로 선택하거나 기록을 시작·재개하면 첫 장은 즉시 저장합니다. `dataset/labels.csv`에는 같은 시점의 이미지 경로, 0~5 클래스, 조향 방향, 바퀴 속도와 시뮬레이션 시간이 기록됩니다. `episode_*.json`에는 해당 실행의 카메라 해상도와 저장 기준을 기록합니다. Webots를 다시 실행해도 기존 데이터 뒤에 이어 씁니다.

현재 월드의 카메라 해상도는 160×120입니다. 연구 PDF의 640×480은 목표 설정이며 이 첫 수집 월드의 실제 해상도와 다릅니다. 16×16 전처리, 증강, 학습은 수집 원본을 검수한 뒤 별도 단계로 진행합니다. 같은 주행에서 연속으로 얻은 프레임은 서로 매우 비슷하므로 나중에 학습/검증 데이터를 나눌 때는 프레임 단위가 아니라 `episode_id` 또는 트랙 종류 단위로 분리하세요.

## 첫 수집 권장 순서

1. 각 클래스별로 짧은 파일럿 주행을 기록합니다. 정지선 화면을 먼저 확인하고 애매하면 5번 클래스는 보류합니다.
2. `labels.csv`와 `images`의 수량이 맞는지 확인하고, 클래스별 샘플 영상을 직접 봅니다.
3. 조명, 트랙, 카메라 시점이 다른 월드를 추가한 뒤 본 수집량을 늘립니다. PDF의 2만~3만 장은 최종 시뮬레이션 목표이며 첫 파일럿 목표는 아닙니다.

운전은 사람이 하고 라벨도 사람이 선택합니다. 현재 수집기는 자동 라벨링이나 환경 무작위화를 수행하지 않습니다.

## 1회성 모터 동작 확인

컨트롤러 폴더에 `drive_once.json`을 만들고 Webots에서 시뮬레이션을 재설정하면 지정한 시간만큼 바퀴를 구동한 뒤 정지합니다. 예: `{"duration_s":1.5,"left_speed":1.2,"right_speed":1.2}`. 시간은 최대 5초, 속도 단위는 rad/s입니다. 명령 파일은 시작 시 소비되고, 측정 결과는 `drive_once_result.json`에 기록됩니다. 이 동작은 자료 수집을 켜거나 클래스를 임의로 지정하지 않습니다.

## 학습용 목록 만들기

수집 원본은 그대로 두고, `C:\AICAR\webot\prepare_ult_dataset.py`를 실행하면 `dataset/training_manifest.csv`와 `dataset/training_manifest_report.json`이 만들어집니다. 정지 중 중복 프레임과 같은 구간의 너무 촘촘한 프레임을 제외합니다. 새 자료를 모은 뒤 다시 실행하면 목록을 새로 계산합니다. CNN 학습에는 원본 `labels.csv`가 아닌 `training_manifest.csv`를 입력으로 사용하세요.

현재 수량과 클래스별 분포는 `training_manifest_report.json`에서 확인하세요. 새로 수집할 때마다 목록을 갱신해야 합니다. 학습과 검증은 같은 실행의 연속 프레임을 나누지 말고 실행 또는 환경 단위로 분리하세요.
