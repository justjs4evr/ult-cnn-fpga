# Webots 차선 중심 + ULT-CNN 보조 제어

Webots에서 `C:\AICAR\webot\worlds\ult_cnn_hybrid_case1_3m.wbt` 또는
`C:\AICAR\webot\worlds\ult_cnn_hybrid_17.wbt`를 열고 시뮬레이션을 시작한다.
원본 월드와 기존 CNN 체크포인트는 수정하지 않았다.

일반 사용에서는 45초 자동 종료가 없다. 이전 시험처럼 차량이 멈춘 채
실행 버튼만 눌러도 움직이지 않으면 상단 원형 화살표의 **Reload World**를
눌러 컨트롤러와 차량 위치를 다시 시작한다. 현재 시험 세계에는 수동 화살표
운전 기능이 없다. 제한시간이 필요한 시험에서만 환경변수
`ULT_CNN_HYBRID_TEST_SECONDS=45`를 설정한다.

## 제어 순서

1. 중앙 카메라의 밝기 범위에 맞춰 흰 차선을 검출한다.
2. 여러 높이에서 실제 좌우 선이 함께 보이면 그 중간을 주행 목표로 삼는다.
3. 한 선만 보이면 최근 위치와 예상 차선 폭으로 다른 선의 위치를 추정하고 감속한다.
4. 일반/급회전 CNN 예측은 기하학적 조향 방향과 맞을 때만 작은 보정으로 사용한다.
   다만 가까운 두 선이 사라지고 영상의 진행 방향도 CNN의 급회전 방향과
   일치하면 `confirmed_corner`로 감속하고 강하게 회전한다.
5. 두 선이 잠시 모두 사라진 직각 코너에서는 CNN 방향으로 최대 약 4초간 천천히 회전해 차선을 다시 찾는다.
6. `stop` 예측만으로 정지하지 않는다. 카메라에서 횡단보도 줄무늬도 확인될 때 정지한다.

콘솔의 `cnn=sharp_left`는 CNN 예측이며 바퀴 명령 자체는 아니다.
실제 동작은 `mode`, `steer`, `wheels` 값을 함께 확인한다. 코드를 수정한 뒤
Webots의 **Reload World**를 눌러야 실행 중인 컨트롤러에 반영된다.

사용 모델: `C:\AICAR\webot\ult_cnn_training\output_current_six_binary\best_model.pt`.
라벨 순서는 `straight, left, right, sharp_left, sharp_right, stop`이다.
이 컨트롤러의 바퀴 속도는 e-puck 실험값이며 실제 로봇의 라즈베리파이 조향값이 아니다.

## 확인한 범위

- 3m 트랙 45초: 278회 판단 중 두 선 검출 167회. 최대 시작점 변위 1.13m.
- 급회전 17번 맵 45초: 278회 판단 중 두 선 검출 187회. 최대 시작점 변위 1.34m.
- 저장 영상 표본 각 100장에서 횡단보도 정지 조건은 횡단보도 91장, 직진 0장,
  급좌·급우회전 각 0장에서 성립했다. 이 표본은 실시간 주행 성공률이 아니다.

주행 기록은 `C:\AICAR\webot\ult_cnn_training\webots_hybrid_live_test\`에 있다.
현재 기록에는 차선 폴리곤이나 코스 완주 판정이 없으므로 두 월드의 완주 여부는 검증되지 않았다.
교차로 정지 장면은 별도의 형상 검출이 부족해 `stop` 클래스만으로 정지시키지 않는다.
