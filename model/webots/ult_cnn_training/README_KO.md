# ULT-CNN 사용 안내와 연구 기록

현재 직접 수집·분류·학습·Webots 시험은 **[직접 학습 사용 안내](../../ULT_CNN/USER_GUIDE_KO.md)**를 따라 진행하세요. 사용자 코드와 설명서는 `C:\AICAR\ULT_CNN`으로 이동했습니다. `C:\AICAR\ULT_CNN_START.cmd`를 더블클릭하면 실행 메뉴가 열립니다. 새 작업은 전용 폴더의 `train_classified_images.py`를 사용하며, 아래 내용은 초기 manifest 기반 학습부터 이어진 연구 기록입니다.

## 초기 ULT-CNN 학습

이 폴더는 Webots 중앙 카메라 영상과 `training_manifest.csv`로 6클래스 ULT-CNN을 학습합니다. 기존 `ult_cnn_train.py`의 미완성 데이터 준비 부분은 건드리지 않습니다.

## 실행

수집 후 학습용 목록과 맵별 분할 목록을 순서대로 갱신합니다. 그다음 이 폴더에서 학습합니다.

```powershell
.\.venv\Scripts\python.exe ..\prepare_ult_dataset.py
.\.venv\Scripts\python.exe .\build_split_manifest.py
.\.venv\Scripts\python.exe .\train.py
```

기본값은 최대 60회 학습, 배치 크기 32입니다. `split_manifest.csv`에 적힌 이전 case1 수집분으로 학습하고 별도 수집 실행 1개로 개발 중 검증을 합니다. 새 3m case1, 공식 IRO 타일, 기타 트랙은 각각 전체 맵 계열을 외부 평가용으로 보관합니다. 조명만 다른 같은 맵은 같은 그룹입니다. 개발 검증은 동일한 옛 case1 맵이므로 독립적인 맵 평가 결과가 아닙니다. 새로운 월드를 추가하면 `build_split_manifest.py`의 `world_family()`에 계열을 명시해야 합니다.

## 전처리와 모델

중앙 카메라 영상의 위쪽 25%를 제외하고 흑백으로 변환합니다. 64×64로 축소한 뒤 기본 모드에서는 127을 기준으로 이진화하고, 평균 축소로 16×16 입력을 만듭니다. `--preprocess-mode grayscale`을 지정하면 이진화 없이 명암을 유지할 수 있습니다. 전처리 모드는 체크포인트에도 저장합니다. 실제 ESP32/FPGA 입력을 만들 때도 선택한 모델과 같은 순서와 값을 사용해야 합니다.

모델은 Conv2D(3필터) → MaxPool → Conv2D(6필터) → MaxPool → Dense(12) → 6클래스 출력으로 구성된 1,440개 파라미터 ULT-CNN입니다. 상대적으로 적은 클래스에 손실 가중치를 적용합니다. 세 카메라를 모두 같은 라벨로 복제하지 않고, 첫 기준 모델은 중앙 카메라만 사용합니다.

## 결과

현재 데이터는 수집 실행별로 분리할 수 있지만, 조명·바닥의 이름은 메타데이터에 없습니다. 검증 점수는 같은 월드에서의 기준 결과이며, 새로운 물리 환경에서의 성능을 뜻하지 않습니다.
